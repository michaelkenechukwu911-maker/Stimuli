# Stimuli

**Stimuli** is an Android floating overlay application built in Kotlin. It provides on-screen 2D image rigging and animation tools designed to run seamlessly over third-party applications (such as video editors, drawing apps, or CapCut).

---

## 🌟 Key Features

* **Floating Screen Overlay:** Draw and control rigs directly over other running applications.
* **2D Canvas Rigging:** Interact with and animate key elements on top of existing screen content.
* **Kotlin & Modern Android Architecture:** Lightweight and efficient background service management.
